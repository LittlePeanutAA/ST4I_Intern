# ST4I_Intern

Các project thực tập ở ST4I về kiểm tra lỗi sản phẩm công nghiệp, gộp từ các repo cũ. Mỗi folder là một repo trước đây, lịch sử commit vẫn được giữ.

| Folder | Nội dung |
|---|---|
| [SurfaceDefect](SurfaceDefect) | Phát hiện lỗi bề mặt bằng học không giám sát (PaDiM trong Anomalib) |
| [InspectContour](InspectContour) | Phát hiện lỗi hình dạng 2D từ contour bằng xử lý ảnh truyền thống (OpenCV, C++) |
